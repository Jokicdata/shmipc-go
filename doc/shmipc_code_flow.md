## 二、核心组件说明

### 2.1 Session（会话）

**文件**: [session.go](file:///d:/proj/shmipc-go/session.go)

Session 是 shmipc 的核心组件，负责管理进程间的通信会话。

```go
type Session struct {
    nextStreamID    uint32                    // 下一个 Stream ID（客户端奇数，服务端偶数）
    config          *Config                   // 配置
    dispatcher      dispatcher                // 事件分发器
    connFd          int                       // 连接文件描述符
    streams         map[uint32]*Stream        // Stream 映射表
    acceptCh        chan *Stream              // 接受 Stream 的通道
    sendCh          chan sendReady            // 发送通道
    bufferManager   *bufferManager            // 缓冲区管理器
    queueManager    *queueManager             // 队列管理器
    isClient        bool                      // 是否为客户端
    // ...
}
```

**关键方法**:
- `Server(conn, config)` - 创建服务端 Session
- `newSession(config, conn, isClient)` - 内部构造函数
- `OpenStream()` - 创建新 Stream（客户端）
- `AcceptStream()` - 接受 Stream（服务端）
- `Close()` - 关闭会话

### 2.2 Stream（流）

**文件**: [stream.go](file:///d:/proj/shmipc-go/stream.go)

Stream 是逻辑通信通道，支持双向数据传输。

```go
type Stream struct {
    id              uint32                    // Stream ID
    session         *Session                  // 所属 Session
    recvBuf         *linkedBuffer             // 接收缓冲区
    sendBuf         *linkedBuffer             // 发送缓冲区
    pendingData     *pendingData              // 待处理数据
    recvNotifyCh    chan struct{}             // 接收通知通道
    closeNotifyCh   chan struct{}             // 关闭通知通道
    inFallbackState bool                      // 是否处于降级状态
    callback        *StreamCallbacks          // 异步回调
}
```

**关键方法**:
- `BufferWriter()` - 获取写入缓冲区
- `BufferReader()` - 获取读取缓冲区
- `Flush(endStream)` - 刷新发送缓冲区
- `Close()` - 关闭 Stream
- `ReleaseReadAndReuse()` - 释放并复用缓冲区

### 2.3 BufferManager（缓冲区管理器）

**文件**: [buffer_manager.go](file:///d:/proj/shmipc-go/buffer_manager.go)

管理共享内存中的数据缓冲区。

```go
type bufferManager struct {
    lists        []*bufferList            // 按大小排序的缓冲区链表
    mem          []byte                   // 共享内存映射
    minSliceSize uint32                   // 最小切片大小
    maxSliceSize uint32                   // 最大切片大小
    path         string                   // 共享内存路径
    refCount     int32                    // 引用计数
    mmapMapType  MemMapType               // 映射类型
    memFd        int                      // memfd 文件描述符
}
```

**关键方法**:
- `allocShmBuffer(size)` - 分配缓冲区
- `recycleBuffer(slice)` - 回收缓冲区
- `readBufferSlice(offset)` - 读取缓冲区切片

### 2.4 QueueManager（队列管理器）

**文件**: [queue.go](file:///d:/proj/shmipc-go/queue.go)

管理共享内存中的元数据队列。

```go
type queueManager struct {
    path        string                    // 队列路径
    sendQueue   *queue                    // 发送队列
    recvQueue   *queue                    // 接收队列
    mem         []byte                    // 共享内存映射
    mmapMapType MemMapType                // 映射类型
    memFd       int                       // memfd 文件描述符
}

type queueElement struct {
    seqID          uint32                 // Stream ID
    offsetInShmBuf uint32                 // 数据在共享内存中的偏移量
    status         uint32                 // 流状态
}
```

**关键方法**:
- `put(element)` - 写入队列
- `pop()` - 读取队列
- `markWorking()` - 标记正在工作
- `markNotWorking()` - 标记工作完成

### 2.5 EpollDispatcher（事件分发器）

**文件**: [event_dispatcher_linux.go](file:///d:/proj/shmipc-go/event_dispatcher_linux.go)

基于 epoll 的事件分发器。

```go
type epollDispatcher struct {
    epollFd        int                         // epoll 文件描述符
    conns          map[int]*connEventHandler   // 连接映射
    pendingLambda  []func()                    // 待执行函数
    isShutdown     bool                        // 是否已关闭
}

type connEventHandler struct {
    fd             int                         // 文件描述符
    callback       eventConnCallback           // 回调接口
    readBuffer     []byte                      // 读取缓冲区
    onWriteReadyCh chan struct{}               // 写就绪通道
}
```

**关键方法**:
- `runLoop()` - 运行事件循环
- `newConnection(file)` - 创建新连接
- `post(f)` - 投递任务

## 九、热重启流程

### 9.1 热重启概述

热重启允许服务端在不中断现有连接的情况下进行升级或重启。

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                            热重启流程                                            │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│      旧服务端进程                      新服务端进程                              │
│  ┌──────────────────┐               ┌──────────────────┐                        │
│  │                  │               │                  │                        │
│  │  1. 接收热重启请求 │               │  启动中...       │                        │
│  │                  │               │                  │                        │
│  │  2. 发送热重启事件 │──────────────►│                  │                        │
│  │     typeHotRestart│               │                  │                        │
│  │     (epoch ID)    │               │                  │                        │
│  │                  │               │                  │                        │
│  │  3. 等待确认      │◄──────────────│  4. 接收热重启事件│                        │
│  │                  │               │     映射共享内存  │                        │
│  │                  │               │                  │                        │
│  │                  │               │  5. 发送确认      │                        │
│  │                  │               │     typeHotRestartAck                     │
│  │                  │               │                  │                        │
│  │  6. 完成热重启    │               │  6. 接管连接      │                        │
│  │     关闭旧进程    │               │     开始处理请求  │                        │
│  │                  │               │                  │                        │
│  └──────────────────┘               └──────────────────┘                        │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 9.2 热重启详细流程

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                          热重启详细流程                                          │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  服务端发起热重启:                                                               │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                           │  │
│  │  listener.HotRestart(epoch)                                               │  │
│  │  ├─ 检查状态（不能已在热重启中）                                           │  │
│  │  ├─ 设置 state = hotRestartState                                          │  │
│  │  ├─ 遍历所有 Session:                                                     │  │
│  │  │   ├─ 检查握手是否完成                                                  │  │
│  │  │   ├─ session.hotRestart(epoch, typeHotRestart)                         │  │
│  │  │   │   └─ sendCh <- sendReady{nil, hotRestartEvent, nil}                │  │
│  │  │   └─ hotRestartAckCount++                                              │  │
│  │  └─ go checkHotRestart()  // 启动检查协程                                 │  │
│  │                                                                           │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
│  客户端处理热重启:                                                               │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │

│  │  handleHotRestart(session, hdr, buf)                                      │  │
│  │  ├─ epochID := binary.BigEndian.Uint64(buf[:8])                           │  │
│  │  ├─ dispatcher.post(func() {                                              │  │
│  │  │       session.manager.handleEvent(typeHotRestart, params)              │  │
│  │  │   })                                                                   │  │
│  │  └─ SessionManager 处理热重启事件                                         │  │
│  │      ├─ 创建新的 Session 连接到新服务端                                   │  │
│  │      ├─ 映射共享内存（使用相同的 epoch）                                  │  │
│  │      └─ 发送 typeHotRestartAck 确认                                       │  │
│  │                                                                           │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
│  服务端确认热重启:                                                               │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                           │  │
│  │  handleHotRestartAck(session, hdr, buf)                                   │  │
│  │  ├─ epochID := binary.BigEndian.Uint64(buf[:8])                           │  │
│  │  ├─ 检查 epochID 是否匹配                                                 │  │
│  │  ├─ hotRestartAckCount--                                                  │  │
│  │  └─ 如果 hotRestartAckCount == 0:                                         │  │
│  │      ├─ state = hotRestartDoneState                                       │  │
│  │      └─ sessions.onHotRestart(true)  // 通知所有 Session                  │  │
│  │                                                                           │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## 十、错误处理与降级

### 10.1 错误类型

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              错误类型定义                                        │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  错误类型                    说明                    处理方式                   │
│  ─────────────────────────────────────────────────────────────────────────────  │
│  ErrNoMoreBuffer            共享内存不足            降级到进程内存/UDS          │
│  ErrQueueFull               队列已满                重试/等待                   │
│  ErrStreamClosed            Stream 已关闭           返回错误                    │
│  ErrSessionShutdown         Session 已关闭          返回错误                    │
│  ErrSessionUnhealthy        Session 不健康          返回错误                    │
│  ErrTimeout                 操作超时                返回错误                    │
│  ErrConnectionWriteTimeout  连接写超时              关闭连接                    │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 10.2 降级机制

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              降级机制                                            │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  共享内存不足时的降级:                                                           │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                           │  │
│  │  linkedBuffer.alloc(size)                                                 │  │
│  │  ├─ buf, err := bufferManager.allocShmBuffer(size)                        │  │
│  │  │   └─ 如果 err == ErrNoMoreBuffer:                                      │  │
│  │  ├─ allocSize := bufferManager.allocShmBuffers(sliceList, size)           │  │
│  │  │   └─ 尝试从多个链表分配                                                 │  │
│  │  └─ 如果仍然不足:                                                          │  │
│  │      ├─ sliceList.pushBack(newBufferSlice(nil, make([]byte, remain), ...))│  │
│  │      ├─ isFromShm = false  // 标记为进程内存                              │  │
│  │      └─ atomic.AddUint64(&stats.allocShmErrorCount, 1)  // 统计错误       │  │
│  │                                                                           │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
│  发送时的降级:                                                                   │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                           │  │
│  │  stream.Flush(false)                                                      │  │
│  │  ├─ 如果 !sendBuf.isFromShareMemory():                                    │  │
│  │  │   └─ inFallbackState = true  // 标记为降级状态                         │  │
│  │  └─ 如果 inFallbackState:                                                 │  │
│  │      └─ writeFallback(state, ErrNoMoreBuffer)                             │  │
│  │          ├─ 生成 fallbackDataEvent                                        │  │
│  │          ├─ 将数据直接通过 UDS 发送                                       │  │
│  │          ├─ session.openCircuitBreaker()  // 开启熔断                     │  │
│  │          └─ atomic.AddUint64(&stats.fallbackWriteCount, 1)                │  │
│  │                                                                           │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
│  接收降级数据:                                                                   │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                           │  │
│  │  handleFallbackData(session, h, buf)                                      │  │
│  │  ├─ 解析 fallback 数据                                                    │  │
│  │  ├─ session.openCircuitBreaker()  // 开启熔断                             │  │
│  │  ├─ atomic.AddUint64(&stats.fallbackReadCount, 1)                         │  │
│  │  └─ handleStreamMessage(stream, wrapper, state)  // 正常处理              │  │
│  │                                                                           │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 10.3 熔断机制

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              熔断机制                                            │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  开启熔断:                                                                       │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                           │  │
│  │  func (s *Session) openCircuitBreaker() {                                 │  │
│  │      if !atomic.CompareAndSwapUint32(&unhealthy, 0, 1) {                  │  │
│  │          return  // 已经在熔断状态                                        │  │
│  │      }                                                                    │  │
│  │      // 30秒后自动恢复                                                    │  │
│  │      time.AfterFunc(30*time.Second, func() {                              │  │
│  │          atomic.StoreUint32(&unhealthy, 0)                                │  │
│  │      })                                                                   │  │
│  │  }                                                                        │  │
│  │                                                                           │  │

│  │      if !s.IsHealthy() {                                                  │  │
│  │          return nil, ErrSessionUnhealthy                                  │  │
│  │      }                                                                    │  │
│  │      // ... 正常创建 Stream                                               │  │
│  │  }                                                                        │  │
│  │                                                                           │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
```
