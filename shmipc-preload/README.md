## 一、概述

### 1.1 功能介绍

shmipc-preload 是一个基于 LD_PRELOAD 技术的透明代理工具，能够自动将应用程序的本地 IPC 连接（UDS/TCP loopback）转换为 shmipc 连接，实现零拷贝通信加速，无需修改应用程序代码。

### 1.2 核心特性

- **零代码修改**：应用程序无需任何修改即可使用
- **自动检测**：自动识别 UDS 和 TCP loopback 连接
- **透明降级**：不支持的场景自动回退到原始 socket
- **简单易用**：只需 LD_PRELOAD 一个 .so 文件
- **高性能**：大包场景下延迟降低 2-3 倍

### 1.3 适用场景

| 场景 | 支持状态 | 说明 |
|------|----------|------|
| qperf 性能测试 | ✅ 支持 | UDS/TCP loopback 自动加速 |
| sockperf 性能测试 | ✅ 支持 | 本地回环测试加速 |
| Redis 本地连接 | ✅ 支持 | UDS 连接加速 |
| MySQL 本地连接 | ✅ 支持 | UDS 连接加速 |
| 自定义 IPC 应用 | ✅ 支持 | 任何使用 UDS/loopback 的程序 |

### 2.3 为什么需要两个 .so 文件？

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                     为什么需要两个 .so 文件？                                      │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  核心原因：C 和 Go 的编译模型不同，无法直接编译成单个 .so                           │
│                                                                                 │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                     编译模型对比                                          │  │
│  │                                                                          │  │
│  │   C 语言：                                                                │  │
│  │   源代码 (.c) → 编译器 (gcc) → 目标文件 (.o) → 链接器 → 共享库 (.so)      │  │
│  │                                                                          │  │
│  │   Go 语言 (CGO)：                                                         │  │
│  │   源代码 (.go) → cgo 工具 → C 桩代码 + Go 桩代码 → 编译 → 共享库 (.so)    │  │
│  │                                                                          │  │
│  │   问题：                                                                   │  │
│  │   - Go 使用 go build -buildmode=c-shared 只能生成独立的 .so              │  │
│  │   - C 代码无法直接嵌入 Go 编译流程                                         │  │
│  │   - Go 运行时需要单独初始化                                               │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
│  解决方案：动态链接                                                              │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                          │  │
│  │   1. Go 代码编译为独立共享库 (libshmipc_go.so)                            │  │
│  │      - 包含 CGO 导出的 C 兼容函数                                        │  │
│  │      - 包含 Go 运行时                                                    │  │
│  │      - 包含 shmipc-go 核心库                                             │  │
│  │                                                                          │  │
│  │   2. C 代码编译为独立共享库 (libshmipc.so)                                │  │
│  │      - 包含 socket API 劫持函数                                          │  │
│  │      - 动态链接到 libshmipc_go.so                                        │  │
│  │      - 通过 extern 声明调用 Go 导出函数                                  │  │
│  │                                                                          │  │
│  │   3. 运行时动态链接器自动加载依赖                                          │  │
│  │      - LD_PRELOAD 加载 libshmipc.so                                      │  │
│  │      - 动态链接器检测到依赖 libshmipc_go.so                              │  │
│  │      - 自动加载 libshmipc_go.so 并解析符号                               │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 2.5 组件说明

| 组件 | 语言 | 文件 | 编译产物 | 功能 |
|------|------|------|----------|------|
| C 拦截层 | C | shmipc_preload.c | libshmipc.so | 劫持 socket API，判断连接类型，调用 Go 接口 |
| CGO 桥接层 | Go | shmipc_bridge.go | libshmipc_go.so | 导出 C 兼容接口，封装 shmipc-go 调用 |
| 核心库 | Go | shmipc-go | (包含在 libshmipc_go.so 中) | 实现共享内存零拷贝通信 |

```

│  │  }                                                                       │  │

│                                                                                 │
```

## 四、CGO 互操作详解

### 4.1 CGO 基本原理

CGO 是 Go 语言提供的 C 语言互操作机制，允许：
1. Go 代码调用 C 函数
2. C 代码调用 Go 函数
3. Go 和 C 之间传递数据

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           CGO 工作原理                                           │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  Go 源代码                                                                       │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │  package main                                                            │  │
│  │                                                                          │  │
│  │  /*                                                                      │  │
│  │  #include <stdio.h>                    // C 代码块                        │  │
│  │  void hello() { printf("Hello\n"); }                                     │  │
│  │  */                                                                      │  │
│  │  import "C"                              // CGO 导入                      │  │
│  │                                                                          │  │
│  │  //export MyFunc                         // 导出 Go 函数供 C 调用         │  │
│  │  func MyFunc(x C.int) C.int {            // Go 函数                       │  │
│  │      return x * 2                                                        │  │

│  │                                                                          │  │
```

### 4.2 Go 导出函数供 C 调用

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                      Go 导出函数供 C 调用                                        │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  Go 代码 (shmipc_bridge.go)                                                     │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                          │  │
│  │  package main                                                            │  │
│  │                                                                          │  │
│  │  import "C"                                                              │  │
│  │  import "unsafe"                                                         │  │
│  │                                                                          │  │
│  │  // 关键：//export 指令导出函数供 C 调用                                   │  │
│  │  //export ShmipcOpenStream                                               │  │
│  │  func ShmipcOpenStream(fd C.int) C.int {                                 │  │
│  │      // 1. 获取 Session                                                  │  │
│  │      session := sessions[int(fd)]                                        │  │
│  │                                                                          │  │
│  │      // 2. 调用 shmipc-go 核心库                                          │  │
│  │      stream, err := session.OpenStream()                                 │  │
│  │      if err != nil {                                                     │  │
│  │          return C.int(-1)                                                │  │
│  │      }                                                                   │  │
│  │                                                                          │  │
│  │      // 3. 保存 Stream 并返回 ID                                          │  │
│  │      streamID := int(stream.StreamID())                                  │  │
│  │      streams[streamID] = stream                                          │  │
│  │      return C.int(streamID)                                              │  │
│  │  }                                                                       │  │
│  │                                                                          │  │
│  │  //export ShmipcWrite                                                    │  │
│  │  func ShmipcWrite(streamID C.int, data unsafe.Pointer, length C.long) C.long {│
│  │      // 1. 获取 Stream                                                   │  │
│  │      stream := streams[int(streamID)]                                    │  │
│  │                                                                          │  │
│  │      // 2. C 指针转 Go 切片                                               │  │
│  │      buf := C.GoBytes(data, C.int(length))                               │  │
│  │                                                                          │  │
│  │      // 3. 写入共享内存                                                   │  │
│  │      writer := stream.BufferWriter()                                     │  │
│  │      n, _ := writer.WriteBytes(buf)                                      │  │
│  │      stream.Flush(false)                                                 │  │
│  │                                                                          │  │
│  │      return C.long(n)                                                    │  │
│  │  }                                                                       │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
│  编译后生成的 C 头文件 (libshmipc_go.h)                                          │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │

│  │  #ifdef __cplusplus                                                      │  │
│  │  extern "C" {                                                            │  │
│  │  #endif                                                                   │  │
│  │                                                                          │  │
│  │  // CGO 自动生成的 C 函数声明                                             │  │
│  │  extern int ShmipcOpenStream(int fd);                                    │  │
│  │  extern long ShmipcWrite(int streamID, void* data, long length);         │  │
│  │  extern long ShmipcRead(int streamID, void* data, long length);          │  │
│  │  extern int ShmipcCloseStream(int streamID);                             │  │
│  │  // ... 其他导出函数                                                      │  │
│  │                                                                          │  │
│  │  #ifdef __cplusplus                                                      │  │
│  │  }                                                                       │  │
│  │  #endif                                                                   │  │
```

```
│  │                                                                          │  │
│  │  2. 栈切换                                                                │  │
│  │     - C 使用系统栈 (由操作系统分配)                                       │  │
│  │     - Go 使用 goroutine 栈 (由 Go 运行时管理，可增长)                     │  │
│  │     - CGO 负责在两种栈之间切换                                            │  │
│  │                                                                          │  │
│  │  3. Go 运行时初始化                                                       │  │
│  │     - 首次调用 Go 函数时，Go 运行时自动初始化                             │  │
│  │     - 初始化调度器、GC、内存分配器等                                      │  │
│  │     - 这就是为什么 libshmipc_go.so 包含 Go 运行时                         │  │
│  │                                                                          │  │
│  │  4. 参数传递和返回值                                                      │  │
│  │     - 基本类型直接通过寄存器/栈传递                                       │  │
│  │     - 指针类型需要特殊处理（见下文内存管理）                               │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 4.7 内存管理与数据传递

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                          内存管理与数据传递                                       │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  C 和 Go 有不同的内存管理模型：                                                   │
│                                                                                 │

│  │                                                                          │  │
│  │   C 内存模型                     Go 内存模型                             │  │
│  │  ┌─────────────────────┐       ┌─────────────────────┐                  │  │
│  │  │ 手动管理            │       │ GC 自动管理         │                  │  │
│  │  │ malloc/free         │       │ 堆上分配            │                  │  │
│  │  │ 栈上分配            │       │ 栈上分配（逃逸分析）│                  │  │
│  │  │ 无 GC               │       │ 有 GC               │                  │  │
│  │  └─────────────────────┘       └─────────────────────┘                  │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
│  数据传递方式：                                                                   │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                          │  │
│  │  1. 值传递（基本类型）- 无拷贝，直接传递                                   │  │
│  │  ┌────────────────────────────────────────────────────────────────────┐  │  │
│  │  │  C 代码:                    Go 代码:                               │  │  │
│  │  │  int fd = 3;                func ShmipcOpenStream(fd C.int) C.int {│  │  │
│  │  │  int ret = ShmipcOpenStream(fd);    // fd 值直接传入               │  │  │
│  │  │                              }                                     │  │  │
│  │  └────────────────────────────────────────────────────────────────────┘  │  │
│  │                                                                          │  │
│  │  2. 指针传递 - 需要数据拷贝                                               │  │
│  │  ┌────────────────────────────────────────────────────────────────────┐  │  │
│  │  │  C 代码:                    Go 代码:                               │  │  │
│  │  │  char *data = ...;          func ShmipcWrite(data unsafe.Pointer,  │  │  │
│  │  │  long len = 1024;                            length C.long) C.long {│  │  │
│  │  │  ShmipcWrite(data, len);        // C.GoBytes 会拷贝数据到 Go 内存   │  │  │
│  │  │                                buf := C.GoBytes(data, C.int(length))│  │  │
│  │  │                            }                                     │  │  │
│  │  └────────────────────────────────────────────────────────────────────┘  │  │
│  │                                                                          │  │
│  │  3. 字符串传递 - 需要转换                                                 │  │

│  │  │  char *path = "/tmp/sock";  func ShmipcCreateClientSession(        │  │  │
│  │  │  ShmipcCreateClientSession(fd, path);        fd C.int, path *C.char)│  │  │
│  │  │                            ) C.int {                               │  │  │
│  │  │                                // C.GoString 会拷贝字符串到 Go 内存  │  │  │
│  │  │                                goPath := C.GoString(path)          │  │  │
│  │  │                            }                                     │  │  │
│  │  └────────────────────────────────────────────────────────────────────┘  │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
│  重要提示：数据拷贝的性能影响                                                     │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                          │  │
│  │  C.GoBytes() 和 C.GoString() 会进行内存拷贝，这会带来一定开销。           │  │
│  │                                                                          │  │
│  │  但在本项目中，这个开销是可接受的，因为：                                   │  │
│  │  1. shmipc 的零拷贝优势远大于 CGO 的拷贝开销                              │  │
│  │  2. 大数据传输通过共享内存，CGO 只传递指针和长度                           │  │
│  │  3. 实际数据写入共享内存时不需要额外拷贝                                   │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
```

## 七、编译安装

### 7.1 系统要求

- **操作系统**: Linux (内核 3.17+，支持 memfd_create)
- **架构**: x86_64 或 arm64
- **Go 版本**: 1.20+
- **GCC**: 7.0+

### 7.2 编译

```bash
cd shmipc-preload
make
```

编译输出：
```
libshmipc_go.so   # Go 共享库（包含 shmipc 核心功能）
libshmipc.so      # C 预加载库（用户 LD_PRELOAD 此文件）
```

### 7.3 安装

```bash
sudo make install
```

安装后使用：
```bash
LD_PRELOAD=/usr/local/lib/libshmipc.so <your-program>
```

## 九、故障排查

### 9.1 验证是否生效

```bash
# 开启调试日志
SHMIPC_LOG=4 LD_PRELOAD=./libshmipc.so <your-program>
```

### 9.2 常见问题

#### 问题 1：找不到 libshmipc_go.so

```
error while loading shared libraries: libshmipc_go.so: cannot open shared object file
```

解决方案：
```bash
# 方法 1：设置 LD_LIBRARY_PATH
export LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH
LD_PRELOAD=./libshmipc.so <your-program>

# 方法 2：安装到系统目录
sudo make install
```

#### 问题 2：没有加速效果

排查步骤：
```bash
# 1. 确认日志中显示 [shmipc]
SHMIPC_LOG=4 LD_PRELOAD=./libshmipc.so <your-program>

# 2. 确认是本地连接
# shmipc 仅对 UDS 和 TCP loopback 有效
```

## 附录

### A. 交付清单

```
libshmipc.so      # C 预加载库（用户 LD_PRELOAD 此文件）
libshmipc_go.so   # Go 共享库（被 C 库动态链接）
```

### B. 支持的连接类型

| 连接类型 | 支持状态 | 说明 |
|----------|----------|------|
| Unix Domain Socket | ✅ | 自动检测并加速 |
| TCP Loopback (127.0.0.1) | ✅ | 自动检测并加速 |
| IPv6 Loopback (::1) | ✅ | 自动检测并加速 |
| 跨机器 TCP | ❌ | 自动回退到原始 socket |
